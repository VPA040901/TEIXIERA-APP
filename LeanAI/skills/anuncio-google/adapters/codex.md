## Pesquisa web neste runtime

Codex acessa a web pelas capacidades de busca e de navegação disponíveis na instalação
(busca web nativa e, quando habilitado, o plugin `browser`).

Antes do Passo 2, confirmar que há acesso à web nesta sessão. Se não houver — sandbox sem
rede, por exemplo — **parar e avisar**: sem pesquisa real, o Passo 2 (pesquisa de palavras-chave) produziriam
dados inventados, o que esta skill proíbe.

Toda afirmação de volume, concorrência ou CPC precisa vir de uma busca real desta
sessão. Nunca de memória.
