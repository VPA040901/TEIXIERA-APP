## Pesquisa web neste runtime

- **Busca:** ferramenta `WebSearch`
- **Leitura de página:** ferramenta `WebFetch`

Para páginas longas ou pesadas de HTML, buscar `https://r.jina.ai/<URL>` com o `WebFetch`
devolve markdown mais limpo.

Toda afirmação de volume, concorrência ou CPC precisa vir de uma busca real desta
sessão. Nunca de memória.
